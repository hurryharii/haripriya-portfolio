# Haripriya — Engineering Portfolio

A responsive, single-page portfolio built with plain HTML, CSS and JavaScript.

## Preview locally
Open `index.html` in a browser. An internet connection is needed for the Google Fonts; the page otherwise works without a build step.

## Before publishing
1. Replace `hello@example.com` in `index.html` with the email address you want public.
2. Add your actual LinkedIn and GitHub links when ready.
3. Review project descriptions and add photographs, code links, and results as the projects develop.
4. Confirm whether you want the university name and all project details public.

## Free deployment with GitHub Pages
1. Create a GitHub repository named `haripriya-portfolio` (or `<your-username>.github.io` for a root site).
2. Upload the contents of this folder to the repository root.
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
5. Wait for the published URL shown in the Pages section.

No framework, build command, API key, or paid hosting is required.
